# 🔒 Política de Privacidade — LinkWeb SP

Repositório oficial destinado à disponibilização da Política de Privacidade da LinkWeb SP, incluindo os serviços de atendimento e comunicação realizados por meio da API oficial do WhatsApp Business (Meta).

## 📌 Objetivo

Garantir transparência sobre a coleta, utilização, armazenamento e proteção dos dados pessoais de clientes e usuários, considerando a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018).


## 🛡️ Privacidade e proteção de dados

A política contempla:

- Coleta e tratamento de dados pessoais.
- Atendimento e comunicação pelo WhatsApp.
- Finalidades do tratamento de dados.
- Segurança e armazenamento das informações.
- Direitos dos titulares dos dados.


## 📂 Estrutura do repositório

- `index.html` — Página da Política de Privacidade.
- `README.md` — Documentação do repositório.
